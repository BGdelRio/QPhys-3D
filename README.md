# QPhys-3D

QPhys-3D is a teaching innovation project developed for the Quantum Physics course in the Physics degree at the University of Valladolid (Spain). The project aims to support conceptual understanding, active learning and formative assessment through accessible and reusable educational resources, including interactive slides, Socrative quizzes, Quantum Trivia activities, Jupyter notebooks and audiovisual materials.

The repository provides the materials developed during the project as Open Educational Resources (OER), with interactive notebooks that can be launched directly in Google Colab without local installation.
